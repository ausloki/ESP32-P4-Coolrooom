⚙️ Operational Settings

The target coolroom temperature. The compressor switches ON once the room is half the Compressor Hysteresis value above this, and OFF the same amount below it — so the room cycles evenly around whatever you set here. Compared live against the Coolroom Temperature (Primary Control) probe, shown as the big number in the center of the gauge above.
How far above Setpoint the room can drift before the High Temperature alarm fires — and it has to stay that warm for a full 5 minutes straight first, so a brief door-open blip won't trigger it. Example: Setpoint 2.0°C + this value 3.0°C = alarm above 5.0°C. Measured against the same Coolroom Temperature probe as Setpoint, and drives the pulsing "HIGH TEMPERATURE" banner and the 🔔 alarm icon.
The same idea as Alarm High Delta, but for the room running too cold. Fires the Low Temperature alarm once the room is this many degrees below Setpoint for a full 5 minutes. Also measured against the Coolroom Temperature probe.
The temperature band the compressor cycles within around Setpoint (sometimes called the "differential"). A smaller value keeps the room closer to Setpoint but cycles the compressor on and off more often — more wear; a larger value cycles it less often but lets the room drift further each cycle. Compared against the Coolroom Temperature probe, and also sets the threshold for the No-Cooling alarm (which fires if the compressor has run for over an hour but the room still hasn't dropped below Setpoint + half this value).

🛠️ Advanced Settings

🔐 System Administration

Backup & Restore

Saves every control parameter — Setpoint, both Alarm Deltas, Compressor Hysteresis, defrost timing, door/no-cool/ice alarm thresholds — to backup.json on the SD card, so they can be recovered after a factory reset or lost device settings. Also runs automatically whenever the setpoint changes, not just when you click this.
Reads backup.json back off the SD card and applies every saved parameter immediately, overwriting whatever is currently set. Also runs automatically once at boot if a backup file exists — this button is for restoring it manually without a reboot.

Logs Management

Lists the daily temperature log files on the SD card (one per day, plus a running events.csv of alarm/fault/defrost events) so you can pick one — Download saves it to your computer, Refresh re-reads the file list, and Delete permanently removes the selected file from the SD card to free up space. Deletion cannot be undone, so double-check the filename first.

Touchscreen Access PIN

The 4-digit code required to reach the Settings screens on the physical touchscreen unit itself — it doesn't affect any sensor or reading, it only controls who can change settings by walking up to the coolroom. Starts at 0000 until changed here or from the touchscreen's own "Change PIN" screen; changing it in either place updates the same PIN.
