Relay Outputs

⚠️ Relay board not seen on RS485 — outputs cannot be commanded.
OutputStateEnabled
Enabled controls whether an output is allowed to energise at all — separate from the feature switches on the other tabs, which control whether the function runs. Disabling the Siren Relay keeps alarms, notifications and logging exactly as they are but leaves an external siren silent. Disabling any output also drops it immediately.

Touchscreen Access PIN

The 4-digit code required to reach Settings on the physical touchscreen. Starts at 0000 until changed.

Controller

Restart reboots the controller. Settings are kept, relays drop for the few seconds it takes to come back, and the compressor off-delay starts again from zero on boot.

Factory Reset erases every stored setting — setpoint, alarm limits, defrost configuration, calibration offsets, ntfy server and topic, the touchscreen PIN, and the Home Assistant API toggle — then reboots to firmware defaults. Wi-Fi credentials are cleared too, so the controller comes back on its own access point and has to be re-joined to your network. There is no undo.
