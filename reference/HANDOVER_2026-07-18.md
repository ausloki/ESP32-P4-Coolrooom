## Implementation Details

### YAML Modifications
**File:** `esp32-p4-coolroom.yaml` (lines ~2260-2540)

#### Arc Widget Definitions
```yaml
- arc:
    id: home_temp_arc
    align: CENTER
    y: 118
    width: 372
    height: 372
    bg_opa: TRANSP
    arc_color: col_blue
    arc_width: 16
    rotation: 225
    start_angle: 0
    end_angle: 270
    value: 50
    indicator:
      arc_opa: TRANSP
    knob:
      bg_opa: TRANSP
```
- **Value range:** 0–100% (representing -20°C to 15°C)
- **Update via handlers:** `lvgl.arc.update` with lambda value conversion

#### Temperature-to-Arc Conversion Formula
```cpp
int percent = (int)((temp_celsius + 20.0f) / 35.0f * 100.0f);
// Maps: -20°C → 0%, 0°C → 57%, 15°C → 100%
```

#### Sensor Handlers
- **probe1_temp (Coolroom):**
  - Updates `lbl_coolroom_temp_large` label
  - Updates `home_temp_arc` with converted temperature value
  - Runs every 2 seconds
  
- **probe3_temp (Ambient):**
  - Updates `lbl_ambient_temp_large` label
  - Updates `home_ambient_arc` with converted temperature value
  - Runs every 10 seconds

- **setpoint (Number Control):**
  - Updates `lbl_setpoint_status` label with formatted string
  - Updates `home_setpoint_arc` with converted temperature value
  - Triggered on user change

### Icon Visual Feedback Architecture

#### Status Icons (Left Sidebar)
All four control icons now provide real-time visual feedback by changing color to reflect their active state:

**Relay-Bound Icons:**
- **Compressor icon** (❄️, position x=20 y=55)
  - **Color:** Green (#30D158) when relay ON, grey (#888888) when OFF
  - **Update mechanism:** `relay_compressor` on_turn_on/off handlers directly update icon color
  - **Control:** Hardware relay state (hysteresis control loop)
  
- **Light icon** (💡, position x=20 y=195) [TOUCHABLE]
  - **Color:** Orange (#FF9F0A) when relay ON, grey (#888888) when OFF
  - **Update mechanism:** `relay_light` on_turn_on/off handlers directly update icon color
  - **Control:** Hardware relay state OR soft trigger via settings
  - **Touch action:** Toggles relay on/off

**Control Logic-Bound Icons:**
- **Defrost icon** (🔥, position x=20 y=135)
  - **Color:** Orange (#FF9F0A) when control logic active, grey (#888888) when idle
  - **Update mechanism:** Binary sensor `defrost_mode_active` monitors `ctl_defrost_on_since_ms > 0`
  - **Control:** Defrost scheduling control loop (NOT hardware relay state)
  - **Benefit:** Icon correctly shows orange for passive defrost or any active defrost cycle
  - **Implementation:** `on_state` handler updates icon color in real-time as control flag changes
  
- **Alarm icon** (🔔, position x=20 y=275) [TOUCHABLE]
  - **Color:** Red (#FF453A) when any alarm active, grey (#888888) otherwise
  - **Update mechanism:** Binary sensor `any_alarm_active` monitors `ctl_alarm_high_active || ctl_alarm_low_active`
  - **Control:** Alarm evaluation control loop (NOT hardware relay state)
  - **Touch action:** Soft reset (clears alarm flags without disabling relay)
  - **Implementation:** `on_state` handler updates icon color in real-time as alarm flags change

#### Icon Color Update Implementation
```yaml
# Relay-bound icon (example: compressor)
relay_compressor:
  on_turn_on:
    - lvgl.label.update:
        id: ui_compressor_icon
        text_color: col_green  # Synchronous update
  on_turn_off:
    - lvgl.label.update:
        id: ui_compressor_icon
        text_color: col_grey   # Synchronous update

# Control logic-bound icon (example: defrost)
binary_sensor:
  - platform: template
    id: defrost_mode_active
    lambda: 'return id(ctl_defrost_on_since_ms) > 0;'
    on_state:
      - lvgl.label.update:
          id: ui_defrost_icon
          text_color: !lambda 'return x ? id(col_orange) : id(col_grey);'
```

#### Design Principle
All icons reflect their **control function**, not just hardware state:
- **Compressor & Light:** Bound to relay state (can enable/disable via hardware relay settings)
- **Defrost & Alarm:** Bound to control logic state (can trigger via software settings without relay)
- This separation allows flexible operation modes with soft triggers and passive cycles

### Color Palette Extensions
```yaml
col_blue:   #0A84FF  (coolroom arc, snowflake)
col_cyan:   #00BCD4  (setpoint arc)
col_pink:   #FF1493  (ambient arc)
```

   - Line widget doesn't support dynamic value updates

### Completed Enhancements
✅ **Dynamic Icon Color Feedback (COMPLETE)**
- Icons now highlight to reflect current control state:
  - **Compressor icon** (❄️) → Green when relay ON, grey when OFF
  - **Light icon** (💡) → Orange when relay ON, grey when OFF
  - **Defrost icon** (🔥) → Orange when control logic active, grey otherwise
  - **Alarm icon** (🔔) → Red when any alarm active, grey otherwise

- **Implementation:**
  - Relay-bound icons (compressor, light): Updates via `relay.on_turn_on/off` handlers
  - Control logic-bound icons (defrost, alarm): Updates via binary sensor `on_state` handlers
  - All icon colors update in real-time as control state changes

- **Key Feature:** Defrost and alarm icons are NOT dependent on relay state
  - Defrost icon highlights when `ctl_defrost_on_since_ms > 0` (passive or active defrost)
  - Alarm icon highlights when `ctl_alarm_high_active || ctl_alarm_low_active`
  - This enables soft triggers and passive operation modes
